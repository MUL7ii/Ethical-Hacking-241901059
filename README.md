## Aim of Each Exercise

### Exercise 1 – Footprinting via Search Engines, Web Services, and Social Networking Sites
- **Aim:** To collect basic information about a target organization or network using search engines, public web services, and social networking sites, without directly touching the target's systems.

### Exercise 2 – Website, Email, Whois, DNS, and Network Footprinting
- **Aim:** To gather detailed technical information about a target's website, email servers, domain registration (Whois), DNS records, and network range using footprinting tools.

### Exercise 3 – Session Hijacking Using Various Tools
- **Aim:** To understand and demonstrate how an attacker can hijack an active web session between a client and server using packet-sniffing and cookie-replay tools.

### Exercise 4 – Detect Session Hijacking
- **Aim:** To understand and demonstrate session-hijacking vulnerabilities using Cross-Site Scripting (XSS) in a controlled environment, and to verify the protection offered by the HttpOnly cookie flag.

### Exercise 5 – Web Server Reconnaissance Using Various Tools
- **Aim:** To understand and perform web server reconnaissance using different tools to gather information about a target server, its services, and configurations.

### Exercise 6 – Enumerate Web Server Information
- **Aim:** To perform web server enumeration and gather detailed information about a target server, including DNS records, technologies, open ports, services, and potential vulnerabilities.

### Exercise 7 – Web Application Reconnaissance Using Various Tools
- **Aim:** To gather information about the structure, technologies, and possible entry points of a target web application.

### Exercise 8 – Web Spidering
- **Aim:** To perform a technical SEO/crawl audit of a target website, identifying broken links, redirects, HTTP status codes, and meta-tag issues using web-spidering tools.

### Exercise 9 – Web Application Vulnerability Scanning
- **Aim:** To conduct automated vulnerability scanning of web applications using free/open-source tools, interpret the findings, and understand remediation basics.

### Exercise 10 – Crack FTP Credentials Using a Dictionary Attack
- **Aim:** To perform a dictionary attack on an FTP server using the Hydra tool and crack a weak username/password combination.

### Exercise 11 – Cross-Site Request Forgery (CSRF) Attack
- **Aim:** To demonstrate a Cross-Site Request Forgery (CSRF) attack against the Damn Vulnerable Web Application (DVWA).

### Exercise 12 – Identify XSS Vulnerabilities in Web Applications
- **Aim:** To learn how to identify and experiment with reflected, stored, and DOM-based Cross-Site Scripting (XSS) vulnerabilities in a controlled environment.

### Exercise 13 – Detect Web Application Vulnerabilities Using Various Security Tools
- **Aim:** To use OWASP ZAP to discover common web application vulnerabilities such as XSS, SQLi, CSRF, insecure cookies, and broken authentication.

### Exercise 14 – SQL Injection Attack Against MSSQL to Extract Databases
- **Aim:** To safely detect and demonstrate SQL injection vulnerabilities against a controlled, local database-backed test application and to practice secure-coding and remediation techniques.

### Exercise 15 – Detect SQL Injection Vulnerabilities Using Various Tools
- **Aim:** To use sqlmap to automatically detect (non-destructively) whether input points on a web application are vulnerable to SQL injection, and to collect information needed for remediation.

### Exercise 16 – Footprint a Wireless Network
- **Aim:** To perform wireless network footprinting — identifying nearby networks, their SSIDs, channels, and encryption types — using packet-capture analysis tools.
